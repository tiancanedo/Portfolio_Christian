# YOURSPACE — Student Portfolio Template

A fresh **editorial / earthy green and coral** portfolio template, built using plain HTML, CSS, and JavaScript. No framework, npm install, or build step is required.

## Customize

1. Open `index.html` in VS Code.
2. Replace all items in `[square brackets]` with your classmate's real information.
3. Replace the example GitHub links (`https://github.com/`) and `your.email@example.com` with actual links.
4. Replace the two decorative project illustrations with real screenshots if available.
5. Edit the colors at the top of `style.css` if desired.
6. Preview locally with Live Server, test on mobile, and confirm all links work.

## GitHub Pages deployment

1. Create a **public** GitHub repository, e.g. `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and any asset folders into the **repository root**. Do not upload only the ZIP or put the whole template in an unnecessary outer folder.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. After publishing, the site URL will resemble `https://USERNAME.github.io/portfolio/`.

## Vercel deployment

Import the GitHub repository into Vercel, choose **Other** as the Framework Preset. No build command is needed. Set Output Directory to `.` if necessary so the repository-root `index.html` is served.

## File structure

- `index.html` — content and semantic layout
- `style.css` — responsive visual design
- `script.js` — mobile menu and dynamic footer year
- `README.md` — setup guide

This template intentionally contains **no real student personal information**.

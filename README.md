# Neon Grid — Student Portfolio Template

A second, original portfolio template with a dark tech-inspired design, neon mint and lime accents, responsive navigation, Home / About / Skills / Projects / Contact sections, and no personal information included.

## Customize

1. Open `index.html` and replace all `[YOUR ...]` and `[PROJECT ...]` placeholders.
2. Replace the two sample project descriptions, tags and GitHub links with real ones.
3. Change the `mailto:replace-me@example.com` address to the classmate's professional email.
4. Update colors in the `:root` block in `style.css` if desired.
5. Test it on desktop and mobile; the sample project illustrations are decorative and should be replaced or supplemented with actual project screenshots if required by the instructor.

## Preview

Open `index.html` directly in a browser, or use Live Server in VS Code. No installation or build is required.

## Publish via GitHub Pages

1. Create a new public GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository **root** (not an extra wrapper folder).
3. In repository Settings → Pages, select "Deploy from a branch", branch `main`, folder `/(root)`, and save.
4. Wait for Pages to finish deploying; visit the actual public URL shown by GitHub.

## Publish via Vercel

Import the GitHub repository. Use **Other** framework preset, leave build command empty, and choose `.` for the output directory if Vercel does not serve the repository root automatically.

Free placeholder text, no images, and no private information are included. Google Fonts need network access; fallback fonts are configured.
